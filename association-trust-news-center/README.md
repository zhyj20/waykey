# 广东省信用协会可信资讯中心项目原型

这是面向广东省信用协会的网站升级开发版本。前台保持专业协会门户、行业媒体与智库资讯平台的组合气质；CMS 后台以内容责任、来源证据、审核签发和长期运营为主线。

## 入口

- 网站首页：index.html
- CMS 演示后台：admin/index.html
- CMS 架构说明：cms-architecture.md

## 当前状态

- 项目状态：可交互原型，不是协会正式线上系统
- 索引策略：noindex、nofollow，robots.txt 禁止抓取
- 事实边界：政府公开报道只作为原始来源索引
- 数据状态：CMS 演示数据保存在当前浏览器 localStorage
- 业务状态：未连接协会账号、会员数据库、正式发布接口或微信生态

## 已实现

1. 首页替换为广东省信用协会目标项目，增加现有官网入口与公开资料来源档案。
2. 删除虚构行业统计，改为资料治理状态。
3. 新建 CMS 运营总览、内容台账、审核签发、来源证据、会员报送、专家复核、专题、媒体、权限、日志和系统设置视图。
4. 稿件支持筛选、编辑、保存、提交、退回、审核流转和本地持久化。
5. 提交审核前校验标题、摘要、来源与引用边界。
6. 会员报送可转为稿件，来源材料默认待核验。
7. SEO/GEO 页面检查标题、摘要、来源、发布主体、canonical 和结构化数据。
8. 所有演示状态、未接系统和残余风险均显式标注。

## 主要源码

- index.html / styles.css / app.js：网站首页
- admin/index.html：CMS 页面与工作区结构
- admin/admin.css：后台桌面与移动端样式
- admin/admin.js：数据模型、审核状态机、筛选、编辑、来源和持久化交互
- llms.txt / robots.txt / sitemap.xml / site.webmanifest：原型阶段机器可读边界

## 正式上线前

必须由协会确认主体登记、正式Logo、组织架构、内容责任人、办公信息、制度文件、会员与专家数据。工程侧还需接入服务端数据库、对象存储、真实鉴权、不可抵赖审计日志、正式域名、网站发布、微信生态、索引提交和AI答案监测。
